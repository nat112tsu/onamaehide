# おなまえかくし

キャラクターチャット/ロールプレイアプリのスクリーンショットから、自分の表示名を
検出し、塗りつぶしでマスキングしてダウンロードできるツールです。

## プライバシーについて

**画像は一切サーバーに送信・保存されません。** OCR・マスキング・書き出しの
すべての処理はこのブラウザ内（クライアントサイド）で完結します。

- OCR（PaddleOCR / PP-OCRv6）に必要なモデルファイルはすべて `public/paddle-ocr/`
  配下に同梱しており、外部CDNへの通信は発生しません。
- OCRが内部で使うONNX Runtime WebのWASM実行環境も `public/ort/` 配下に同梱して
  自己ホストしています（未設定だとjsDelivr CDNから読み込む既定動作のため、
  明示的に自己ホストパスを指定しています）。
- ページをリロード/離脱すれば、アップロードした画像データはメモリ上から消えます。
- バックエンドAPIは存在せず、完全な静的サイトとして動作します。

## 使い方

1. 画像をアップロード（ドラッグ&ドロップ、複数枚可・最大10枚・1枚10MBまで）
2. OCRが自動的に文字列を検出し、枠線で表示
3. マスクしたい名前を「マスクする名前を登録」欄に入力（表記ゆれがあれば複数登録可）
   → 曖昧一致で全ページから自動検出してマスク候補に追加
4. 手動でも矩形マスク・丸スタンプ（タップで即配置）を追加・移動・リサイズ・削除可能（拡大表示にも対応）
5. 塗りつぶし色を選択
6. 1枚ならPNG、複数枚ならZIPでまとめてダウンロード。スマートフォンでは「共有」から
   端末の共有メニューに直接渡すこともできる（複数枚は個別のPNGとして共有）

## 開発

```bash
npm install
npm run dev
```

## 技術スタック

- Vite + React + TypeScript
- Tailwind CSS
- PaddleOCR / PP-OCRv6（OCR、多言語対応、ONNX Runtime Webで実行、自己ホスト）
- Canvas API（マスキング描画）
- JSZip（複数画像のZIP書き出し）
- Web Share API（スマートフォンでの共有。非対応環境ではボタンを表示しない）
- M PLUS Rounded 1c（UIフォント。常用漢字・かな等にサブセットして自己ホスト。
  範囲外の文字はシステムフォントにフォールバック）

## 既知の制約

- OCRエンジン（PaddleOCR）は装飾的なフォントなどでは検出漏れが起こる場合が
  あります。自動検出後は必ず内容を確認し、漏れがあれば手動でマスクを追加
  してください。
- モバイル端末では、マスク描画中はページの拡大縮小（ピンチズーム）ではなく
  ツール内蔵のズームボタンをご利用ください。
- OCRモデル（`public/paddle-ocr/`、約31MB）とONNX Runtime Webの実行環境
  （`public/ort/`、ブラウザ互換性のため複数のWASMバリアントを同梱・約76MB）を
  含むため、初回読み込み時のダウンロード量が比較的大きくなります。
